# HR_Analysis_Dashboard
# 📊 Power BI Data Analysis Dashboard

## 📌 Overview

This project is an interactive **Power BI Data Analysis Dashboard** designed to transform raw business data into meaningful and actionable insights.

The dashboard provides a clear overview of key performance indicators, trends, and business performance through interactive visualizations, slicers, and filters.

---

## 🎯 Objectives

* Analyze business performance using Power BI.
* Create meaningful KPIs and measures.
* Identify trends and performance patterns.
* Build interactive and user-friendly visualizations.
* Present data-driven insights for better decision-making.

---

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Interactive Visualizations**

---

## 🔄 Data Preparation

Power Query was used to prepare the data before creating the dashboard.

Key steps included:

* Removing duplicate records
* Handling missing values
* Changing data types
* Renaming columns
* Cleaning and transforming data
* Creating calculated fields
* Preparing data for analysis

---

## 📊 Dashboard Features

The dashboard includes:

* KPI Cards
* Bar Charts
* Line Charts
* Pie/Donut Charts
* Tables and Matrix
* Slicers
* Interactive Filters
* Trend Analysis
* Category-wise Analysis
* Drill-down functionality

---

## 📈 Key KPIs

The dashboard tracks important business metrics such as:

* **Total Employee**
* **Active Employee**
* **Attrition Count**
* **Attrition Rate**
* **Average Age**
* **Average Experience**


---

## 🧮 DAX

DAX was used to create calculated measures and support dynamic analysis.

Examples of calculations include:

* Total Sales
* Total Profit
* Average Sales
* Profit Margin
* Percentage Growth
* Year-over-Year Performance

---

## 🔍 Key Insights

The dashboard helps users identify:

* Overall business performance
* Top-performing products or categories
* Sales and revenue trends
* Profitability patterns
* Regional or customer performance
* Areas requiring improvement

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. Check the data source connection.
4. Refresh the dataset if required.
5. Use the slicers and filters to explore the dashboard.
6. Interact with the visualizations to analyze business performance.
